Proyecto de aprendizaje: conectar una web con Supabase

Este proyecto es una prueba simple para entender cómo tu página se comunica con la base de datos de Supabase. No usa React ni Vite. Es solo un archivo HTML para aprender más fácil.

1. Estado de conexión

Comprueba si la página puede hablar con Supabase usando la URL y la API key.

Todavía no probaste la conexión.

2. Login básico

Busca en la tabla usuarios una fila donde coincidan nombre y password.

No hay sesión iniciada.

3. Probar cualquier tabla

Escribe el nombre de una tabla. Si existe y la key tiene permiso, aparecerán los datos.

Aquí aparecerá el resultado.

4. Qué estás aprendiendo

La URL indica a qué proyecto de Supabase se conecta la web. La API key es la llave pública que permite hacer consultas según los permisos configurados por el administrador.

La prueba espera una tabla llamada usuarios con columnas nombre, password, nivel, exp y rango. Si tu amigo cambió esos nombres, hay que cambiar esta prueba.

Advertencia: este login es solo para aprender. En una web real no conviene guardar contraseñas como texto visible en una tabla.
